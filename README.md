A fast drop-in for make.fun's own csv-reader 1.0.0: it answers exactly as csv-reader does on every case, but reads the text with whole-line and whole-field scans instead of one character at a time.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each one alone with `run()` from `solve.js`, and writes `/output/answers.json`. Outside a container, `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` stand in for `/input` and `/output`. Node 22, no dependencies, no network.
